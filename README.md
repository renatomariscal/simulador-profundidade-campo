# Simulador de Profundidade de Campo

Simulador interativo em português, desenvolvido em HTML, CSS e JavaScript, sem dependências externas.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (por exemplo, `simulador-profundidade-campo`).
2. Envie o arquivo `index.html` para a raiz da branch `main` (você também pode enviar este README).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione **main** e **/(root)** e clique em **Save**.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/simulador-profundidade-campo/` (substitua o usuário e o nome do repositório).

Para publicar na raiz `https://SEU-USUARIO.github.io/`, use um repositório chamado `SEU-USUARIO.github.io`.

## Desenvolvimento local

Abra `index.html` no navegador. Não é necessário instalar dependências.
